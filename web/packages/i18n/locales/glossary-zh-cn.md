# Simplified Chinese glossary

One word for one thing, across the catalog, help and emails. `catalogs.test.ts` holds the first
five rows.

| English             | Chinese            | Not      |
| ------------------- | ------------------ | -------- |
| account             | 账号               | 账户     |
| you                 | 你                 | 您       |
| sign out            | 退出登录           | 登出     |
| workspace           | 工作空间           | 工作区   |
| email               | 邮件               | 电子邮件 |
| node                | 节点               |          |
| license             | 许可证             |          |
| portal, console     | 门户, 控制台       |          |
| connector, provider | 连接器, 身份提供方 |          |

"账号" is what mainland consoles use for a sign-in; "账户" reads as a financial account. "你"
matches the plain voice of the product.
