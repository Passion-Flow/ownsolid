# License

The license covers the whole platform; there are no paid modules. The [License](/license) page shows
its state, expiry and limits, and imports a new one.

## Getting a license

Send the issuer the **deployment ID** shown on the page. It identifies this installation, and a
license is signed for one deployment only.

## Importing

Choose **Import a license file** and pick the file. The file is checked before anything changes, and
every check is shown: a file from another issuer, changed after signing, made for another deployment or adding
no time is refused with the values involved. **Import this license** asks for a reason.

## When it runs out

Ahead of expiry the page and the overview show a renewal notice. After the grace period the
installation keeps running what exists but refuses new work, such as joining nodes, until a valid
license is imported.

## Diagnostics

**Download diagnostics** saves the license state as a file to send to whoever supports you.
