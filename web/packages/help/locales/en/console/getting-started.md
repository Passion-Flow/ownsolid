# Getting started

The overview is the first page after signing in. It tells you what needs attention, how the fleet
stands and what is left to set up.

## The first steps

A new installation needs three things before people can work on it. The overview lists them under
**Finish setup** until each is done:

1. **Import a license.** Without one, the installation keeps running what exists but refuses new
   work. See [License](help:license).
2. **Add a node.** A node is a server whose GPUs and CPUs the platform manages. See
   [Nodes](help:nodes).
3. **Invite your team.** People sign in with an invitation, or through single sign-on when you set
   it up. See [People and workspaces](help:people-and-workspaces).

## What the overview shows

- **Needs attention** names nodes that stopped reporting, tasks and emails that failed in the last
  day, and the license when it is close to expiring. Each item links to where it is fixed.
- **Fleet health** counts nodes by state. Choosing a state opens the [nodes](/nodes) filtered to it.
- If a source cannot be read, the overview says which part is unknown and offers **Try again**; the
  rest of the page still shows.

## Finding your way

- Press **Ctrl K** (or **⌘ K**) to open the command menu: it finds pages, nodes, tasks, people and
  workspaces, and runs actions such as switching the theme.
- Pin a page you use daily with the pin next to its name in the navigation.
- The help link at the top of every page opens the article about that page.

## Working with the API

The [API reference](/help/api) lists the operations of this entrance. Search by name or path,
then choose **Save the contract** to download the contract for this installed version.
If a download fails, check the connection to this installation and choose **Save the contract** again.
