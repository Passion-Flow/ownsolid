# Models

[Models](/models) lists what you can call in the workspace chosen in the switcher. Each row is a name an
administrator published to that workspace. It is the name you put in the `model` field of a call.

## Reading the list

**Can be called** means a call would be taken now. **Not available** means the model is published but nothing is
serving it at the moment, so calls fail until an administrator starts it again. Press a tile to see only those
models, and search by the name or by the model behind it. The address keeps your filters, so you can share the list
as you see it.

## What a model offers

Open a model to see the name to call, the base URL, the model behind it, what it comes from, what it is good for,
how much context it takes, and its license.

**Fine-tuned here** means the model was trained further on this installation from the one named under **Comes
from**. **Published model** means it arrived as its authors released it.

Prices are not ready in this release, and neither is trying a model on the page. To call one now, choose **Issue a
key** and follow [My API keys](/keys).

## If you see no models

No model is published to this workspace yet, so ask an administrator. If you expected one, check that the workspace
in the switcher is the right one. A model that was withdrawn no longer appears here at all.
