# What is supported

[What is supported](/support) lists every option the product offers, such as operating systems,
accelerators and installation sizes, and whether this release can use it.

## States

| State              | Meaning                                                               |
| ------------------ | --------------------------------------------------------------------- |
| Available          | Works in this release.                                                |
| Planned            | Not in this release. The roadmap item that brings it is shown.        |
| Needs your licence | Works, but only under a licence you hold for a third-party component. |
| Not supported      | Will not work, for the reason shown.                                  |

The page comes from the same declaration the installer and the forms use, so it cannot differ from
what they offer.
