# 支持情况

[支持情况](/support)列出产品提供的每一个选项，例如操作系统、加速卡和安装规模，以及本版本能否使用它。

## 状态

| 状态       | 含义                                                 |
| ---------- | ---------------------------------------------------- |
| 可用       | 在本版本中可以使用。                                 |
| 规划中     | 不在本版本中。页面会显示引入它的路线图条目。         |
| 需你方授权 | 可以使用，但只能在你持有第三方组件授权的情况下使用。 |
| 不支持     | 无法使用，原因如页面所示。                           |

此页面与安装程序和各个表单使用同一份声明生成，因此不会与它们提供的选项不一致。
