# 你的账号

[你的账号](/account)保存你的资料、密码，以及 ownsolid 对你的显示方式。

## 可以修改的内容

- **资料**：你的显示名称。
- **密码**：修改密码会退出你的其他会话。
- **语言**：所有页面使用的语言。右上角的用户菜单也可以修改它。
- **登录服务**：绑定或解除绑定单点登录提供方上的账号。解除绑定需要输入密码。

每个页面顶部的主题和密度按钮可以在浅色和深色之间、在宽松和紧凑的行距之间切换。它们和语言一样，会跟随你的账号出现在每个浏览器中。

会话因长时间未操作即将结束前，会有提醒让你选择保持登录。

## 查看你的登录

登录会话列出你在当前入口的有效登录。管理端和门户端分别显示各自的列表。每条记录显示服务器返回的登录方式、登录时间、最后活动时间和到期时间，不推断设备或位置。“当前会话”表示发起本次请求的登录；要退出它，请使用账号菜单中的“退出登录”。

使用“刷新”查看第一页，使用“加载更多会话”继续读取。列表不会在后台自动刷新。部分读取失败时保留之前的页面；游标失效时可以从第一页重新读取。访问被拒绝时会隐藏之前的记录。

要结束其他登录，请选择“结束会话”并输入会话编号。此操作立即终止该会话的访问，且无法撤销。确认结束后会重新读取列表。如果无法确认结果，请先“重新读取”，再明确决定是否重试。仅凭记录消失或服务器返回未找到，无法证明结束成功。页面不会自动再次发送结束请求。如果显示重试等待时间，请等待结束后重试。

修改密码会替换当前浏览器的会话，并结束你的其他所有会话。会话区会开始新的读取，不会沿用之前的“当前会话”标记。
