# 我的 API 密钥

[我的 API 密钥](/keys)列出你在切换器所选工作空间中签发的密钥。密钥让应用或脚本调用一个模型。密钥在到期、被你撤销或你离开工作空间后停用。这里不会出现别人的密钥，你的密钥也不会出现在别人的门户中。

## 签发密钥

1. 选择**签发密钥**，或按 `k`。
2. 按使用它的程序命名，选择模型，并选择有效期。
3. 填写原因（会保存在审计日志中），然后选择**签发**。
4. 复制密钥。它只显示这一次，之后无法再次读取。
5. 选择**完成**。密钥详情会打开，其中有调用所需的信息。

如果没有可选的模型，说明此工作空间尚未发布模型，请联系管理员发布。

如果响应在途中丢失，**重试**会找到同一个密钥，但其密文无法再次显示。请撤销该密钥并重新签发。

## 调用模型

打开密钥可看到**使用此密钥**：Base URL、模型名称，以及 cURL、Python 和 Node.js 的示例调用。每个示例都从 `OWNSOLID_KEY` 环境变量读取密钥，请先设置该变量，不要把密钥写进代码。

Python 和 Node.js 示例需要 `openai` 软件包。如果你的组织使用私有证书颁发机构，cURL 需要 `--cacert` 和其证书路径，Python 需要把 `SSL_CERT_FILE` 设为该路径，Node.js 需要把 `NODE_EXTRA_CA_CERTS` 设为该路径。

## 轮换和撤销

**轮换**为密钥生成新密文，只显示一次。可以选择旧密文继续有效多久（最长七天），以便不中断地迁移正在使用它的程序。如果密文已泄露，请选择立即停用。

**撤销**会立即停用密钥。需要输入密钥名称确认。

## 查看调用记录

打开密钥可查看用它发起的每次调用，最新的在前：运行时间、结果、使用的令牌数和耗时。
