# 模型

[模型](/models)列出你可以在切换器所选工作空间中调用的内容。每一行都是管理员发布到该工作空间的一个名称，也就是调用时填写在 `model` 字段中的名称。

## 查看列表

**可调用**表示现在发起调用会被受理。**不可用**表示模型已发布，但目前没有实例在提供服务，在管理员重新启动之前调用都会失败。点击统计卡片可只看对应的模型，也可以按调用名称或其背后的模型搜索。地址会保留筛选条件，因此你可以把当前看到的列表分享给别人。

## 模型提供的信息

打开一个模型，可以看到调用名称、Base URL、背后的模型、它的来源、适用场景、可使用的上下文长度和许可协议。

**本地微调**表示模型是在此安装环境中基于**基于**一栏所列的模型继续训练得到的。**已发布模型**表示它与作者发布时的版本一致。

此版本尚未提供价格，也还不能在页面上试用模型。如需立即调用，请选择**签发密钥**，并按[我的 API 密钥](/keys)操作。

## 如果看不到模型

说明此工作空间尚未发布模型，请联系管理员。如果你认为应该有模型，请确认切换器中选择的工作空间是否正确。已撤下的模型不会再出现在这里。
