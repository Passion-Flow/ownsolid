# 节点

节点是运行 ownsolid 代理程序的服务器。[节点](/nodes)页面列出所有节点及其状态，并可以添加、修改和移除节点。

## 添加节点

1. 选择 **添加节点**。页面会创建一个一次性加入令牌，并显示要在新服务器上运行的命令。
2. 按显示的内容运行命令。这些命令不会把令牌留在 shell 历史记录中。
3. 代理程序加入后，节点会出现在列表中。一个令牌只能加入一个节点；未使用的令牌可以撤销。

只有在平台持有有效[许可证](help:license)时，节点才能加入。

## 状态

| 状态   | 含义                                                             |
| ------ | ---------------------------------------------------------------- |
| 在线   | 代理程序最近上报过。                                             |
| 无响应 | 代理程序已有一段时间没有上报，但还没有久到判定节点离线。         |
| 离线   | 代理程序停止上报。请检查服务器是否运行，以及能否连接到控制平面。 |
| 已停用 | 管理员已让节点停止服务，不会再有新工作分配给它。                 |

列表上方的卡片统计各个状态，选择后会筛选列表。

## 修改节点

在列表中打开一个节点，可以查看它的系统信息和最近的任务。

- **采集信息** 让代理程序重新上报服务器的硬件和软件信息。
- **重命名** 和 **停用** 可以在随后出现的提示中撤销。
- **移除** 无法撤销，因此需要输入节点名称确认。

在列表中选择多个节点，可以一起对它们执行操作。

## 代理程序上报节奏

[代理程序上报节奏](/nodes/pacing)设置代理程序多久上报一次，以及断开连接后如何退避重连。代理程序会在下一次上报时采用新的设置。
