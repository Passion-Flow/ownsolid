# 网关和密钥

[网关和密钥](/gateway)列出调用切换器中所选工作空间模型的密钥。每个密钥只调用一个模型，即网关提供该模型时使用的名称，不能调用其他任何模型。密钥归签发它的人所有：到期、被撤销，或该用户失去工作空间的权限时，密钥即停用。

列表上方的筛选卡片统计一周内到期的密钥和从未使用过的密钥，点击即可筛选列表。打开一个密钥可以查看其详情，以及用它发起的每次调用，最新的在前。

## 签发密钥

1. 选择 **签发密钥**，或按 `k`。
2. 以使用者命名，选择模型，并选择有效期。最长有效期由安装设定。
3. 填写原因，然后选择 **签发**。
4. 复制密钥。它只显示这一次，并且不会以任何人能读回的形式保存。

将密钥作为 Bearer 令牌发送。如果响应在传输中丢失，选择 **重试** 会返回同一个密钥，但无法再次显示其密文：请撤销它并重新签发一个。

## 轮换密钥

**轮换** 为密钥生成一个新密文（只显示一次），名称、模型和所有者保持不变。选择旧密文继续可用多长时间，最长七天，以便使用者无中断地切换。密文泄露时请选择 **不保留**。一个密钥只能轮换一次；之后请轮换替换它的密钥。

## 撤销密钥

**撤销** 会立即并永久停用密钥。你需要输入密钥名称以确认。之后用它发起的调用都会失败。

## 尚未就绪

- 密钥还不能有自己的速率或令牌限额，而是使用工作空间的限额，**超出限额** 卡片会说明这一点。
- 安装程序尚未启动模型网关，因此在它启动之前，安装上不会有经过网关的调用。
- 在控制台提供此功能之前，模型通过 API 发布到网关。

每次签发、轮换和撤销都记录在[审计日志](help:audit-trail)中。
