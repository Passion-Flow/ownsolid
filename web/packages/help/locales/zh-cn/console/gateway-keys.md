# 网关和密钥

[网关和密钥](/gateway)列出调用切换器中所选工作空间模型的密钥。每个密钥只调用一个模型，即网关提供该模型时使用的名称，不能调用其他任何模型。密钥归签发它的人所有：到期、被撤销，或该用户失去工作空间的权限时，密钥即停用。

列表上方的筛选卡片统计一周内到期的密钥和从未使用过的密钥，点击即可筛选列表。打开一个密钥可以查看其详情，以及用它发起的每次调用，最新的在前。

## 将模型发布到网关

密钥按模型发布时使用的名称来调用它。请在[模型服务](/services)中打开部署的页面进行发布：部署正在运行、且测试生成已验证其回答后，**网关** 卡片会提供 **发布到网关**。

1. 选择调用方作为模型名发送的名称。它由模型名称生成，只能使用小写字母、数字、点和连字符，名称在工作空间内只能使用一次。
2. 如果部署所在节点还没有网关，请填写调用方访问它的 HTTPS 地址和网关名称。发布时会注册该网关，并只显示一次它的凭据、网关 ID 和节点 ID：请用它们配置该节点上的网关。
3. 填写原因，然后选择 **发布**。

之后卡片会显示基础 URL、调用示例，以及为该名称 **签发密钥**。如果网关注册后发布失败，其凭据会保留在屏幕上，**重试** 只会重新发布。如果携带凭据的响应丢失，请在对话框中撤销该网关并注册新的网关。

**停止发布** 会从此拒绝对该名称的调用，并列出将停止工作的密钥；你需要输入名称以确认。该名称不能再次发布，部署会继续运行。

## 签发密钥

1. 选择 **签发密钥**，或按 `k`。
2. 以使用者命名，选择模型，并选择有效期。最长有效期由安装设定。
3. 填写原因，然后选择 **签发**。
4. 复制密钥。它只显示这一次，并且不会以任何人能读回的形式保存。
5. 选择 **完成**。密钥详情会打开，并显示 Base URL 以及 cURL、Python 和 Node.js 的示例调用。

将密钥作为 Bearer 令牌发送。如果响应在传输中丢失，选择 **重试** 会返回同一个密钥，但无法再次显示其密文：请撤销它并重新签发一个。

## 轮换密钥

**轮换** 为密钥生成一个新密文（只显示一次），名称、模型和所有者保持不变。选择旧密文继续可用多长时间，最长七天，以便使用者无中断地切换。密文泄露时请选择 **不保留**。一个密钥只能轮换一次；之后请轮换替换它的密钥。

## 撤销密钥

**撤销** 会立即并永久停用密钥。你需要输入密钥名称以确认。之后用它发起的调用都会失败。

## 尚未就绪

- 密钥还不能有自己的速率或令牌限额，而是使用工作空间的限额，**超出限额** 卡片会说明这一点。
- 安装程序尚未启动模型网关，因此在它启动之前，安装上不会有经过网关的调用。
- 网关丢失的凭据目前无法更换：撤销网关会使它提供的所有名称停用。

每次发布、签发、轮换和撤销都记录在[审计日志](help:audit-trail)中。
