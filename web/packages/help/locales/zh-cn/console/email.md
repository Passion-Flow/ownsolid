# 邮件投递

平台通过你的邮件服务器发送邀请、密码重置以及密码已修改的通知。[邮件投递](/mail)显示每封邮件的投递情况。

## 投递状态

| 状态   | 含义                                                           |
| ------ | -------------------------------------------------------------- |
| 等待中 | 等待发送，或等待下一次尝试。                                   |
| 发送中 | 正在交给邮件服务器。                                           |
| 已发送 | 邮件服务器已接收。                                             |
| 失败   | 所有尝试都失败了。错误信息会说明原因，例如无法连接邮件服务器。 |
| 已取消 | 不会再发送。                                                   |

## 重新发送

选中失败的邮件并选择 **重新发送**，每封都会重新排队。在这里也可以输入邮箱地址确认后撤销邀请。
