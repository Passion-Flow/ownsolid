# 审计记录

每一项特权操作都会被记录。[审计记录](/audit)显示谁在何时、从哪里对什么做了什么，以及结果如何。

## 查找事件

- 按操作类型、结果、人员、请求和时间筛选。筛选条件是地址的一部分，因此同事打开同一链接会看到相同的事件。
- 打开事件可以查看详情，并跳转到相关人员，或查看同一请求的所有事件。
- 每个事件都有自己的链接，并且一直有效。
- 列表用你的语言显示每个操作的名称。详情中保留操作标识供脚本和技术支持使用，原因按记录时的原文显示。

## 无法确认此次审计读取

成功读取审计记录或资源的活动记录时，也会记录此次访问。如果响应丢失，此次读取可能已经被记录。请保留提示中的请求编号。“重新读取”会发起一个新请求。返回标签页或网络恢复时，页面不会自行重试。

后续页面读取失败时，已经读取的事件会保留，并提示结果不完整。“重新读取”只重试该页。如果分页位置已失效，“从头读取”会打开新的第一页；读取成功前仍保留旧页面。权限被拒绝时，旧事件会从界面移除。请先联系管理员核对访问权限，再决定是否发起新的读取。
