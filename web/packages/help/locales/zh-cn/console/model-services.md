# 模型服务

[模型服务](/services)显示切换器中所选工作空间提供的模型及其状态。一个部署在一个节点的一整块 GPU 上运行一个模型，并以模型和节点来称呼。列表上方的磁贴按状态统计部署，也可用来筛选列表。

## 节点需要什么

- 在线，amd64 上的 Ubuntu 24.04，至少 12 GiB 内存。
- root 运行的 Docker、NVIDIA Container Toolkit，以及需要你自行加载的批准 vLLM 镜像。
- NVIDIA GPU：驱动 580 或更高版本，关闭 MIG，至少 8 GiB 显存，且大部分显存空闲。

一个节点同时只运行一个部署，因此运行期间其余 GPU 会闲置。

[添加节点](help:nodes)时请选择**提供模型服务**：节点加入后不能更改，随后的步骤会说明如何把镜像带到主机上。

## 部署模型

1. 在这里或模型页面选择**部署模型**，或按 `d`。
2. 选择模型。页面会说明推荐哪块 GPU：符合条件且空闲显存最多的一块。在**高级设置**中可以选择其他 GPU。
3. 阅读**资源占用**，然后选择**部署**。

部署页面会跟踪进度；离开页面后，工作仍会在节点上继续。模型通过一次测试生成后，部署才算运行中。

如果没有位置可以运行该模型，页面会列出各节点的原因。节点报告过期时，**读取 GPU** 会让它重新报告，页面随后自动更新。

## 管理部署

- **启动**：重新运行已停止或失败的部署。
- **检查**：询问节点部署的状态。
- **验证**：运行一次测试生成。
- **停止**：结束服务但保留部署，之后可以重新启动。节点确认后释放 GPU。
- **移除**：删除容器并释放 GPU。部署无法恢复。

停止和移除时，页面会列出将停止响应的网关名称和密钥，并要求你输入模型名称。

## 尚未就绪的内容

副本和扩缩容、选择引擎、自动扩缩容、回滚，以及部署的流量和日志，都会显示提供它们的路线图条目。在此之前，部署最近的任务会显示节点代理报告的内容。
