# 单点登录

单点登录让成员使用公司 Gitea 上的账号登录，而不必使用由 ownsolid 保存的密码。[单点登录](/sso)页面管理连接器。

## 添加连接器

1. 在你的 Gitea 上注册一个 OAuth 应用，回调地址填写对话框中显示的地址。
2. 选择 **添加连接器**，填写提供方地址、客户端 ID 和密钥。新连接器默认处于关闭状态。
3. 打开连接器并运行 **测试连接**。它会指出 Gitea 拒绝了什么，例如客户端 ID、密钥或未注册的回调地址，或者说明无法连接或无法信任 Gitea。
4. 填写原因后开启连接器。

本安装也必须开启单点登录，并且提供方必须获得批准；不满足时页面会提示。

## 关闭连接器

关闭连接器需要输入它的名称确认。关闭会结束通过它登录的会话，并且这些会话不会恢复，因此无法撤销。
