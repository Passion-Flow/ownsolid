Stated 2026-11-04: the user's close friend builds a knowledge base product, DeepParser (https://deepparser.ai/). A knowledge base cannot be an ownsolid selling point and ownsolid should not build one. Integration is with DeepParser only; do not add a second knowledge product (decided 2026-11-04). DeepParser will be deployed through ownsolid and use its models, status and logs (see [[product-direction]]).

**Why:** Avoid competing with a friend's product.

**How to apply:** Do not add knowledge base features or marketing. Treat existing knowledge code and README wording as something to freeze, hide or replace, not extend. Removing code needs the user's decision. See [[mvp-definition]].
